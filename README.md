# Quotely – Daily Quote App

Quotely is a daily quote web application built using HTML, CSS, and JavaScript. It helps users discover inspirational quotes based on their mood, explore different categories, save their favorite quotes, and create custom quote cards.

## Features

- Daily inspirational quotes
- Random quote generator
- Mood-based quote recommendations
- Multiple quote categories
- Search quotes by text, author, or category
- Save and manage favorite quotes
- Copy and share quotes
- Create custom quote cards with different themes
- Light and dark mode
- Track daily streaks and achievements
- Save preferences and progress using Local Storage

## Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage
- Google Fonts

## How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

No backend setup is required.
